# UTDRS Frontend

Unified Threat Detection and Response System - Frontend Application

## Features

- Multi-Page Application (MPA) architecture
- Role-based interfaces (Admin & User)
- Real-time threat monitoring
- Device management
- Vulnerability tracking
- Reporting and analytics
- Dark theme UI with cybersecurity aesthetic

## Technologies

- React 18
- Vite
- Tailwind CSS
- Recharts
- Socket.IO
- React Router
- Axios
